# Consolidação técnica — DocInspector v0.9.8

A v0.9.8 é a versão endurecida para início de uso controlado em campo. Ela foi construída sobre a linha visual/funcional v0.9.x, preservando a v0.8.0 STABLE como baseline histórica de retorno.

Critérios verificados: domínio, persistência IndexedDB, merge/tombstones, sincronização Supabase, evidências, OCR, importação/exportação, PWA/offline, HTML, CSS, JavaScript, Manifest, Service Worker e integridade do pacote.

Não houve migração de banco. Schema Supabase requerido: v6.
